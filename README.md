# Lab: Small ATM

This program allowing person to withdraw money form his\her account and check if the balance is enough to do that.

## How to Run
1. Open the program in your IDE.
2. Enter your balance then.
3. Enter the amount you want to withdraw.
4. check that your balance is enough.

## Example Output
Enter starting balance 
300
Enter the amount you want to withdraw(P.S: enter 0 to exit)
50
Withdrew: $50.0, Balance: $250.0
enter the new amount you want to withdraw:
0
Goodbye!
